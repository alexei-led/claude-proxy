## Summary

First experimental release of claude-proxy: one local Anthropic API endpoint
for explicitly configured native model providers.

## Changes

- Route exact native model IDs through Go's ReverseProxy without body translation,
  response reconstruction, retries or provider fallback.
- Keep subscription OAuth on explicit passthrough routes. Use server-held keys
  for other providers and a separate local authentication header.
- Publish a complete local model catalog. Forward token-count requests only
  when a counting URL is configured.
- Reject unsafe configuration, private-file permissions, browser-origin requests
  and reserved credential query parameters.
- Bound request bodies and concurrent forwarding. Propagate cancellation and
  perform bounded shutdown without a whole-generation timeout.
- Include standalone Claude Code instructions and mixed model-router examples.

## Limitations

This is a prerelease for controlled experiments, not a production-readiness claim.
Local tests use fake providers and dummy credentials.
Saved OAuth refresh, actual Claude Code integration, provider tool/thinking
compatibility, company account behavior and billing remain unverified.
Use non-sensitive data and explicitly authorized destinations.

The proxy does not manage classifier credentials or make incompatible provider
histories work. Configuration and key changes require a restart.
There is no service installation, automatic startup, Docker image or Homebrew tap.

## Assets

macOS and Linux binaries for amd64 and arm64, plus LICENSE and SHA256SUMS.
