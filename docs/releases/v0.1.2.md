## Summary

Homebrew is now the default installation method:

```sh
brew install alexei-led/tap/claude-proxy
```

## Changes

- Add the binary-only formula to `alexei-led/tap` for macOS/Linux on ARM64 and AMD64.
- Update the tap through its existing workflow after each published release.
  The dispatch supplies the exact tag version, including experimental prereleases.
- Document formula-specific Homebrew trust and public example downloads.
- Retain direct release binaries and source builds as alternatives.

## Operation

Installation does not create credentials or configuration, install a service,
or start a listener. Validate a private configuration with `--check`, then
start the proxy manually.

The proxy runtime and native protocol behavior are unchanged.
Provider compatibility, OAuth refresh and billing retain the documented experimental limits.
