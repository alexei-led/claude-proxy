## Summary

The foreground terminal now shows a live proxy view instead of leaving old traffic on screen.

## Changes

- Recent traffic clears after 30 seconds without active requests or new request records. The view keeps the address, registered session count and active request count visible.
- Traffic summaries and `status` include registered client and active request counts and report uncertain process tracking. Clients configured manually do not register, so idle manual clients are not included in the session count.
- Redirected output and dumb terminals keep append-only logs. Managed brokers keep their bounded logs.

## Operation

No configuration changes are required. Restart the foreground proxy after upgrading to use the live view. The terminal restores its previous screen when the proxy exits.
