## Summary

Check the installed binary version with `claude-proxy --version`.

## Changes

- Release binaries print their release tag, such as `claude-proxy v0.4.1`. Source builds without an injected version print `claude-proxy dev`.
- The configuration reference explains how `router_provider` selects a claude-model-router profile for `run` and `connect`, including the default and manual setup.

No configuration migration is required. Existing proxy generations continue to serve their current sessions; new launches after upgrading use the new executable.
