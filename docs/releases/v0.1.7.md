## Summary

Make status failures generation-specific instead of claiming that no proxy is running.

## Changes

- Say when no registration matches the selected config and installed binary. An older or unregistered manual server can still be running.
- Report whether the configured local TCP address accepts a connection, without sending credentials or treating that listener as a verified proxy. Older managed generations may use different ports.
- Label status and stop failures as command failures, not startup failures.

## Operation

A Homebrew upgrade replaces the binary on disk, not processes already running. Restart older manual servers when it is safe to interrupt their clients so they can register with the newer version. This update does not adopt, stop or restart those servers. Matching registered servers still return the same status JSON fields.
