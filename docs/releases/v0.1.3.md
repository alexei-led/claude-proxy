## Summary

Add a process-local `connect` helper for mixed Anthropic and DeepSeek sessions.

## Changes

- Read the selected proxy connection and local token without loading provider keys.
- Check the authenticated local model catalog, then replace the helper with the requested client.
- Preserve unrelated headers, the selected Claude account directory, terminal behavior and exit status. Keep secrets out of command arguments and logs.
- Reject conflicting connection settings and keep saved OAuth unchanged.
- Provide an explicit two-provider `model-proxy-router.json` example. DeepSeek handles low/high worker effort; Opus handles frontier work.

## Upgrade

Existing proxy configuration remains valid. The example filename and provider selection are now `model-proxy-router.json` and `model-proxy`. Existing custom `proxy` profiles still work without migration.

The helper does not start a service or listener. Provider-history compatibility, OAuth refresh and billing retain the documented experimental limits.
