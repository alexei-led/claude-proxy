## Summary

A second start of the proxy no longer takes over from a live but slow broker.

## Changes

- `claude-proxy run` and a foreground start now treat the control socket as stale only when the connection is refused or the socket is missing. Before, any dial failure, such as a timeout on a busy machine, removed a live broker's socket.
- Fix a race in the managed tests that made macOS CI fail at random.

## Operation

No config changes.
