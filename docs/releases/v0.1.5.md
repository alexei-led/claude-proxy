## Summary

Start mixed-provider sessions with one command. `run` automatically starts or reuses a private managed proxy for the selected configuration.

## Changes

- Share a broker across agents using the same configuration and executable. Keep personal and work separate.
- Track registered client processes across exec, not HTTP inactivity. Close only after zero living clients and zero active requests for the idle window; uncertain tracking keeps the broker alive.
- Start a new generation after binary, configuration or selected-key changes without interrupting old clients.
- Add status, idle-only stop and bounded configurable concurrency. Native forwarding and saved OAuth ownership remain unchanged.

## Upgrade

Upgrade the binary before applying the new optional runtime fields; older binaries reject them. Defaults remain eight forwarded requests and a five-minute managed idle timeout. Manual server and connect modes remain available. Detached clients must register independently. No login service or automatic package upgrade is installed.
