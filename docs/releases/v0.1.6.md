## Summary

Reuse matching manually started proxies instead of starting a duplicate managed broker. Foreground logs are now readable, with terminal-only color.

## Changes

- Register manual and managed servers in the same private discovery mechanism. Clients receive the actual address for their selected configuration without guessing ports.
- Report server mode through status. Manual servers use the configured listener and never apply the managed idle timer.
- Report an existing matching server on a repeated foreground start without changing its ownership or interrupting clients.
- Keep background logs structured and private. Human logs escape terminal control characters, omit credentials and honor NO_COLOR.

## Upgrade

Restart older manually started servers once after upgrading so they can register for discovery. Matching still includes the configuration snapshot and installed executable; rolling upgrades remain intact. Unknown processes on occupied ports are never adopted or killed. Existing client configuration and saved OAuth remain unchanged.
